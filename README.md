# KalipheTiles (Windows 11)

Géoréférencement d'images (JPG, PNG, TIFF, MNT 16/32 bits), collage de plusieurs images avec synchronisation des couleurs,
aperçu en direct, relief 3D, MNT OpenTopography, tuiles XYZ / MBTiles / GeoPackage, GeoTIFF, Shapefile, GeoJSON (cadre), KMZ, envoi S3.
Résultats : Documents\KalipheTiles\<id>\ (exports\ contient le cadre GeoJSON).
Journal : Documents\KalipheTiles\kaliphetiles.log — bouton « 🔧 Diagnostic » dans l'application.
Icône : static/icon.png (512×512) — remplacez-la par la vôtre ; le workflow en fait l'icône de l'exe.
